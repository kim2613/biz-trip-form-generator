# 출장신청서 자동 생성기 (김정권 전용)

구글 캘린더 일정 제목을 보고 출장 여부를 판별해서, 회사 양식 그대로의
출장신청서 HTML을 만들어주는 도구입니다.

## 파일 구조

```
출장신청서프로젝트/
├── index.html          # 화면 구조
├── style.css           # 디자인
├── rules.js             # 고정값 + 출장 판별 규칙
├── form-template.js      # 양식 HTML 생성 함수
└── app.js               # 화면 동작 (버튼, 입력, 복사 등)
```

## 사용법

1. `index.html` 을 브라우저로 더블클릭해서 열기
2. "+ 일정 직접 추가" 로 캘린더 일정을 한 줄씩 입력 (또는 "샘플 불러오기")
3. "분석하기" 클릭 → 규칙대로 출장/제외 판별
4. 출장으로 판별된 건마다 "신청서 생성" → "복사하기"
5. 회사 인트라넷 출장신청서 입력칸에 붙여넣기

## 확정된 규칙 (rules.js 안에 있음)

- 제목 끝이 `(지역명)` 또는 `(지역명,시간)` → 출장 ✅
- 제목 앞이 `[지역명]` (과거 습관) → 출장 ✅
- `(원격)`, `(유선)`, `(전화)`, `(영상)` → 출장 아님 ❌
- `연차휴가`, `대체휴가`, `휴가` 포함 → 출장 아님 ❌
- 시간: 항상 09시 ~ 18시
- Project 명/코드: 항상 "미생성"
- 출장자 정보: `rules.js` 맨 위 `FIXED` 값 (본인 정보로 이미 채워져 있음)
- 출장지: 지역명만 (상세주소 X)
- 출발지: 자택 (고정)
- 교통편: 대중교통 (기본값)
- 출장비(교통비/숙박비/일비): 빈칸 (직접 입력)
- 같은 날 여러 건(동시 출장)은 고려하지 않음
- 여러 건이면 날짜 빠른 순서대로, 묻지 않고 전부 분석 결과에 표시

## 본인 정보를 바꾸고 싶을 때

`rules.js` 맨 위에 있는 이 부분만 수정하면 됩니다:

```js
const FIXED = { team: "연계3팀", empNo: "394333", grade: "수석", name: "김정권" };
```
